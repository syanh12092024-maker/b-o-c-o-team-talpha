## Steps
1. Scan conversation hien tai, tim:
   - User corrections (AI lam sai -> user sua)
   - Explicit preferences ('tao thich X', 'dung lam Y')
   - Patterns moi phat hien (architecture, naming, flow)
   - Gotchas/pitfalls da gap

2. Voi moi learning, phan loai:
   - **Preference**: Ghi vao INDEX.md > Preferences
   - **Correction**: Ghi vao INDEX.md > Corrections
   - **Pattern**: Ghi vao INDEX.md > Patterns Learned
   - **Chi tiet dai**: Tao topic file rieng (vd: `.auto-memory/bigquery-gotchas.md`)

3. Update INDEX.md > Topic Files table neu tao file moi

4. Rules:
   - INDEX.md LUON < 50 dong
   - KHONG ghi trung (check truoc khi ghi)
   - Ghi NGAN GON, 1 dong/learning

   - Neu topic file > 100 dong -> tach file
