# Project Brief: AUUS (FAOS v6)

## Muc tieu du an
AI-powered Facebook Ads Optimization System cho e-commerce cross-border (thi truong My, UC).
2 AI Agents tu dong phan tich va quan ly chien dich quang cao Facebook COD.

## Pham vi (Scope)
- Core features:
  - Executive Analyst Agent: Phan tich du lieu ads tu BigQuery
  - Marketing Director Agent: Ra quyet dinh budget/bid/campaign
  - Dashboard UI: Real-time monitoring, Audit trail, Memory viewer
  - FalkorDB Graph: Knowledge graph cho agent memory
  - Multi-project support (stramark, auus1, zen8)
- Nice to have:
  - CAPI push (Conversion API)
  - Stock-aware campaign control
  - Discord/Telegram alerts

## Doi tuong su dung
- E-commerce ad managers quan ly COD campaigns cross-border
- Team lead can giam sat AI decisions

## Tieu chi thanh cong
- AI agents chay daily cycle on localhost (dry-run)
- Dashboard hien thi data real-time
- Audit trail day du cho moi quyet dinh

## Rang buoc
- Deadline: Ongoing development
- Team size: 1 (solo dev + AI assistant)
