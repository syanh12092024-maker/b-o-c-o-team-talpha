Antigravity Là Gì?

Antigravity là AI assistant tích hợp trong code editor (VS Code / Cursor),
có thể đọc file, viết code, duyệt web, chạy lệnh, và giao tiếp bằng ngôn ngữ tự nhiên.

Giao Diện Antigravity

Mở Antigravity

  1. Mở VS Code hoặc Cursor
  2. Nhấn Ctrl + Shift + P
  3. Gõ "Antigravity"
  4. Hoặc click icon 🧠 ở sidebar

Cửa sổ Chat

  • Panel bên phải = chat window
  • Gõ tin nhắn → Enter
  • Antigravity trả lời + gợi ý
  • Có thể attach file, image

🧪 Công Thức Prompt Vàng

CONTEXT + TASK + FORMAT + CONSTRAINTS

Context (Bối cảnh): Bạn là ai, đang làm gì

"Tao là marketer project STRAMARK, đang chạy ads Facebook cho thị trường Romania"


Task (Nhiệm vụ): Bạn cần gì cụ thể

"Phân tích 5 campaign tốn nhiều tiền nhất tuần này và đề xuất pause/scale"


Format (Định dạng): Output dạng gì

"Trình bày dạng bảng, có cột: Campaign, Spend, ROAS, Action (Pause/Scale/Keep)"


Constraints (Ràng buộc): Giới hạn, quy tắc

"Chỉ suggest pause nếu ROAS < 2.0 và spend> $50. Trả lời bằng tiếng Việt"

📝 Cách Tạo Workflow

Workflow = file .md hướng dẫn Antigravity thực hiện 1 quy trình cố định


Ví dụ: .agent/workflows/bao-cao-ads-hang-ngay.md

---
description: Tạo báo cáo ads hàng ngày cho CEO
---
## Quy trình:
1. Đọc file data ads mới nhất trong folder `data/ads/`
2. Tính các KPI: Total Spend, Revenue, ROAS, CPO, Top 5 campaigns
3. So sánh với ngày hôm qua → tính % thay đổi
4. Format thành báo cáo markdown với bảng và emoji
5. Lưu vào `reports/daily_ads_{ngay}.md`

Cách dùng: Gõ /bao-cao-ads-hang-ngay trong chat → Antigravity tự chạy toàn bộ quy trình!

✅ Nên & ❌ Không Nên

✅ NÊN

  • Cung cấp context — bạn là ai, đang làm gì
  • Ra yêu cầu cụ thể — file nào, output gì
  • Chia nhỏ task — 1 yêu cầu = 1 việc
  • Review kết quả — luôn kiểm tra output
  • Dạy context riêng — "ghi nhớ: X luôn = Y"
  • Tạo workflow — lưu quy trình hay dùng
  • Feedback — "sai, sửa lại → cách khác"
  • Mở file trước khi hỏi — để Antigravity thấy

❌ KHÔNG NÊN

  • Share credentials — KHÔNG gõ mật khẩu
  • Tin 100% — luôn verify số liệu quan trọng
  • Hỏi quá vague — "làm gì đó" = kết quả kém
  • Copy paste cả file — mở file, đừng paste
  • Bỏ qua warning — nếu nó cảnh báo, hãy chú ý
  • Chạy lệnh không hiểu — hỏi giải thích trước
  • Dùng data nhạy cảm — thông tin KH riêng tư
  • Bỏ cuộc quá sớm — retry 2-3 lần khác cách

💡 Tips & Tricks Nâng Cao

🔄 Chain Requests (Yêu cầu nối tiếp)
1) Đọc file orders.csv
2) Lọc đơn ROAS > 3.0
3) Export sang Excel
4) Viết email gửi CEO kèm file đó
📎 Multi-file (Nhiều file cùng lúc)
So sánh file sales_stramark.csv vs sales_talpha.csv,
tìm patterns chung và khác biệt giữa 2 markets
🧠 "Dạy" cho phiên làm việc
Từ giờ trong conversation này: khi tao nói "report" thì hiểu là
báo cáo markdown format, có bảng, có so sánh %, có emoji, tiếng Việt
