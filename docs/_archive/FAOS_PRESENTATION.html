FAOS Là Gì?

FAOS = Nền tảng AI giám sát và tự động hóa vận hành E-commerce đa dự án

  • Alert khi ROAS thấp
  • Báo cáo CEO hàng ngày
  • Đề xuất pause/scale ads
  • Monitor stock critical
  • Cross-agent intelligence

🔧 Setup Guide (1/3) — Prerequisites

Yêu cầu hệ thống

Python3.11+python --version
Node.js18+node --version
n8nSelf-hostednpx n8n
GCP AccountBigQuery enabledService account key

Bước 1: Clone & Install

git clone [repo] AGENT
cd AGENT

# Python dependencies
pip install -r requirements.txt

# Frontend dependencies
cd dashboard-ui && npm install && cd ..

🔧 Setup Guide (2/3) — Configuration

Bước 2: Environment Variables

# Copy template
cp .env.template .env

# Điền các giá trị:
GCP_PROJECT_ID=levelup-465304
GOOGLE_APPLICATION_CREDENTIALS=./bigquery_key.json
NEXT_PUBLIC_API_URL=http://localhost:3000
GEMINI_API_KEY=your_key
OPENAI_API_KEY=your_key

Bước 3: BigQuery Key

# Đặt file service account JSON tại root
# File: bigquery_key.json (KHÔNG commit lên git!)

Bước 4: Project Config

# Mỗi project: config/projects/{project_id}.yaml
# Chứa: API keys, shop IDs, ad accounts, team, 3PL config
# Template: config/projects/_template.yaml

🔧 Setup Guide (3/3) — Run

Bước 5: Chạy Dashboard

# Terminal 1: Frontend
cd dashboard-ui && npm run dev
# → http://localhost:3000

# Terminal 2: Backend (Ads Command Center)
python -m uvicorn modules.ads-command-center.backend.main:app --port 3003

# Terminal 3: War Room (optional)
python war_room/orchestrator.py --project zen8

Bước 6: Chạy Agents

# Chạy 1 agent cho 1 project
python -m agents.profit_guardian --project STRAMARK --days 1

# Chạy Coordinator (all agents)
python -m agents.coordinator --project STRAMARK

# Chạy CrewAI crew
python agents/crew/run.py --all-projects

Bước 7: Deploy SQL Views

python tools/deploy_all_views.py --project STRAMARK --apply
