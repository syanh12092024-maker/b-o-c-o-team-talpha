🤖 Module 2: Order Automation (Core)

POS status=8 → Auto tạo đơn 3PL

POS detect status=8 (packing)
        ↓
1 Validate: address, phone, SKU
        ↓
2 Check 3PL stock (GET /get-prod-avails)
        ↓
3 Select courier (cheapest for weight+dest)
        ↓
4 POST /fulfilment/create-order
        │  senderId=3248, courierId=auto
        │  recipient = POS customer info
        │  inventory = POS items → 3PL SKU
        │  COD = POS cod ÷ 100 (bani→RON)
        │  clientReference = "STR-{order_id}"
        ↓
5 Response: orderId + AWB
        ↓
6 Update POS → status=2 (shipped) + tracking
        ↓
7 Save to BigQuery: fulfillment_orders table

📡 Module 3: Status Tracking

Poll 3PL mỗi 2h → Update POS + BigQuery + Alerts

Tracking Flow

Every 2 hours:
  → Get active orders from BQ
  → POST /orders-history
  → For each order:
    ├─ Status changed?
    │  ├─ Yes → Update POS status
    │  │       Update BQ tracking
    │  └─ No  → Skip
    ├─ Stuck > 48h?
    │  └─ Yes → Discord ⚠️ Alert
    └─ Delivered?
       └─ Yes → Queue COD reconcile

💸 Module 4: COD Reconciliation

Daily 08:00:
  1. Fetch delivered orders
     (status=3,16 in POS)

  2. Fetch COD data from 3PL
     (via dashboard / API)

  3. Match by clientReference:
     POS order ID ↔ 3PL refNum

  4. Compare COD amounts:
     ├─ Diff < 5% → ✅ Matched
     └─ Diff ≥ 5% → 🔴 Alert!

  5. Write to BQ:
     cod_reconciliation table

  6. Update P&L Dashboard
