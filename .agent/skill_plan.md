# Kế hoạch nội dung cho kỹ năng: faos-documentation-architect

## 1. Tên và Mô tả
- **Name:** faos-documentation-architect
- **Description:** Thiết kế, xây dựng và cập nhật bộ tài liệu hệ thống end-to-end cho các hệ thống Agentic AI (như FAOS). Sử dụng khi cần tạo tài liệu kiến trúc, hướng dẫn triển khai Agent, đặc tả API và quy trình quản trị cho các dự án AI tự động hóa doanh nghiệp.

## 2. Các tài nguyên đi kèm (Bundled Resources)
- **Templates:**
    - `system_architecture_template.md`: Mẫu tài liệu kiến trúc hệ thống 5 lớp (Data, Orchestration, Agent, Execution, Governance).
    - `agent_implementation_template.md`: Mẫu mô tả chi tiết từng Agent và workflow.
    - `api_spec_template.md`: Mẫu đặc tả tích hợp và API.
    - `ops_governance_template.md`: Mẫu quy trình vận hành và quản trị.
- **References:**
    - `real_world_alignment_checklist.md`: Danh sách kiểm tra để đảm bảo tài liệu khớp với thực tế (dựa trên việc phân tích file PDF kỹ thuật).
